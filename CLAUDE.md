# <Your Project Name>

The project is driven by its specification. System behavior is described in
`specs/` as numbered requirements with references to code.

- **Specification rules** — `specs/README.md`. It is the single normative
  document on the rules.
- **Engineering principles** — `specs/constitution.md` (`ART-*`).
- **Order of work** — invoke the `srs` skill. Mandatory before any code
  change that alters behavior, and when planning a task.
- **Check** — `python3 tools/srs_check.py`.

The three most frequently broken rules:

1. Changing behavior — first find or create the requirement, then write the
   code.
2. `specs/90-traceability.md` is generated by a script. Never edit it by
   hand.
3. **Run builds and tests only with the user's explicit confirmation.**
