# Frames

`F-NNN` — boundaries this project will not cross whatever the evidence says.
A frame is not a hypothesis: no measurement can refute it, because refusing is the whole point.

Each frame keeps a table of what it has turned down and when.
A frame that has refused nothing in a long time is not proof of virtue — it usually means nobody is testing the boundary, or it was drawn where nothing was going to happen.
